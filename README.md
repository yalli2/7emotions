# SEVEN KEYS · 세븐 키
**일곱 감정, 일곱 개의 열쇠 — CBT 기반 성인 감정조절 프로그램**

다인에듀(다인원격평생교육직업학원) HR 분야 성인 대상 감정조절 프로그램 사이트입니다.
교재 *Understanding Your 7 Emotions: CBT for Everyday Emotions and Common Mental Health Problems* (Lawrence Howells, Routledge)의 구조(서론 + 7개 감정 챕터)를 따라 수업용으로 재구성했습니다.

## 페이지
| 파일 | 내용 |
|---|---|
| `index.html` | 프로그램 홈 · 세 가지 원칙 · 커리큘럼 · 우리 반 감정 날씨 |
| `lesson.html?ch=0~8` | 챕터별 실습 (서론, 공포, 슬픔, 분노, 혐오, 죄책감, 수치심, 행복, 종합) |
| `journal.html` | 나의 감정 일지 — 매일 7감정·인내의 창 기록, 흐름 그래프·레이더·달력·열쇠 사용 통계 |
| `board.html` | 강사 라이브 보드 — 방 코드·QR, 챕터/세션별 응답 실시간 차트 |

## 챕터 구성 (각 챕터 공통)
체크인 → 경험 기록(5요소 레이더) → 이해하고 받아들이기(원인·5요소·기능) → 견디고 반응하기 → 감정의 덫(도식·자가점검·나의 덫 그리기) → 덫에서 나오기(CBT 도구) → 퀴즈·실천 다짐

주요 개인 도구: 인내의 창 그래프, Top5 두려움, 상자 호흡, 주의 훈련, 공포→설렘 리프레이밍, 다가가기 사다리(세 개의 원), 활동 계획표(성취·연결·즐거움), 생각 기록, 정의·확인·해결, 폭발↔억누름 균형, 단호한 문장 만들기, 혐오 프로필, 기준 지도, 책임 파이, 관점 바꾸기, 회복 계획, 행복의 바퀴, 관계 지도, 가치 vs 시간, 친절 빙고, 감사 일지, 종합 리포트, 수료증

실시간 활동 유형: 단일/복수 선택, 척도, 퀴즈(정답률), 7감정 체크인(평균 막대 + 나), 레이더, 산점도(우리 반 지도), 세 개의 원 보드, 포스트잇

## 수업 진행
1. 강사: `board.html` → **새 방 만들기** → QR을 화면에 띄우고 챕터(세션) 선택
2. 수강생: QR/링크로 접속 → 닉네임 입력 → 실습
3. 응답은 강사 보드와 모든 수강생 화면에 실시간으로 모입니다.
